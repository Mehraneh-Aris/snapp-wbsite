# Snapp wbsite

A responsive landing page inspired by Snapp, built with HTML, Tailwind CSS, and JavaScript. This project focuses on creating a clean user interface, responsive layouts, and interactive components.

Responsive layout for different screen sizes

RTL layout for Persian content

Custom Persian fonts

Responsive navigation menu

Interactive image slider

Hero section and additional content sections

Tailwind CSS styling and custom theme configuration

Organized project structure
